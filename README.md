
# 💅 Clari Nails Shop

**Catálogo web moderno para Clari Nails Paraguay**, desarrollado para mostrar productos de uñas, Nail Art, herramientas, accesorios y cursos, permitiendo a los clientes realizar pedidos y consultas directamente por WhatsApp.

🌐 **Demo:**
https://nexowebpy.github.io/ClariNailsShop/

---

## ✨ Características

* 💅 Catálogo de productos de belleza y Nail Art
* 🛒 Carrito de compras
* ➕ Control de cantidades
* 🗑️ Eliminación de productos del carrito
* 💰 Cálculo automático del total
* 📲 Pedidos mediante WhatsApp
* 🎓 Sección de cursos
* 👩‍💼 Información sobre Clari Nails
* 🔍 Búsqueda de productos
* 📱 Diseño responsive para celulares, tablets y computadoras
* ⚡ Interfaz rápida y sencilla
* 🔎 Optimización básica para motores de búsqueda
* 🗺️ Sitemap y robots.txt
* 🖼️ Galería e imágenes de productos

---

## 🛍️ Objetivo del proyecto

El objetivo de **Clari Nails Shop** es ofrecer una experiencia de compra sencilla y moderna para los clientes de Clari Nails Paraguay.

La página funciona como un catálogo digital donde los usuarios pueden:

1. Explorar los productos.
2. Consultar precios y características.
3. Agregar productos al carrito.
4. Revisar su pedido.
5. Enviar el pedido directamente por WhatsApp.

---

## 🛠️ Tecnologías utilizadas

Este proyecto fue desarrollado utilizando tecnologías web estándar:

* **HTML5** — estructura del sitio
* **CSS3** — diseño y responsive
* **JavaScript** — interacción y funcionamiento del carrito
* **GitHub Pages** — alojamiento del sitio
* **WhatsApp** — comunicación y recepción de pedidos

## 🛒 Sistema de carrito

El carrito permite al usuario:

* Agregar productos.
* Modificar cantidades.
* Eliminar productos.
* Consultar el subtotal.
* Visualizar el total.
* Preparar el pedido para enviarlo por WhatsApp.

El sistema está desarrollado completamente con **JavaScript**, sin necesidad de un servidor o base de datos.

---

## 💬 Pedidos por WhatsApp

Una de las principales funciones del proyecto es permitir que el cliente envíe su pedido directamente a Clari Nails mediante WhatsApp.

El mensaje generado contiene información como:

```text
💅 Pedido Clari Nails

• Producto 1 x 2
• Producto 2 x 1
• Producto 3 x 3

💰 Total: Gs. XXX.XXX

¡Hola! Quiero realizar este pedido.
```

Esto facilita la comunicación entre el cliente y el negocio.
