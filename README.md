## 📌 Descripción

**ClariNailsShop** es una aplicación web orientada a la gestión de salones de belleza y manicura.

El sistema busca simplificar las tareas administrativas del negocio mediante una plataforma centralizada para organizar la información de clientes, gestionar citas, administrar servicios y controlar el inventario.

El proyecto fue desarrollado con un enfoque en **usabilidad, organización de la información y experiencia de usuario**, buscando ofrecer una herramienta práctica tanto para profesionales como para clientes.

---

## ✨ Funcionalidades

### 👥 Gestión de clientes

* Registro de clientes
* Consulta de información
* Organización de datos
* Administración de la cartera de clientes

### 📅 Gestión de citas

* Programación de citas
* Organización de horarios
* Visualización de reservas
* Gestión de turnos

### 💅 Servicios

* Catálogo de servicios
* Información de cada servicio
* Organización de servicios disponibles
* Gestión orientada a salones de belleza

### 📦 Inventario

* Control de productos
* Organización del inventario
* Seguimiento de existencias
* Administración de recursos utilizados por el negocio

---

## 🎯 Objetivo

El objetivo principal de **ClariNailsShop** es proporcionar una herramienta digital que permita a un salón de belleza centralizar sus operaciones y reducir la dependencia de procesos manuales.

```text
Clientes
   │
   ▼
Citas ──────► Servicios
   │
   ▼
Gestión del negocio
   │
   ▼
Inventario
```

## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/Cbenegas1/ClariNailsShop.git
```

### 2. Acceder al proyecto

```bash
cd ClariNailsShop
```

### 3. Ejecutar

Abrir `index.html` en el navegador.

También se recomienda utilizar **Visual Studio Code + Live Server** durante el desarrollo.
